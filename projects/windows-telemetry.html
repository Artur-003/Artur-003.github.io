Windows Telemetry Lab

Configuring native Windows auditing, PowerShell logging and Sysmon, then using the resulting events to reconstruct user and process activity.

Event ViewerSecurity LogSysmonPowerShellDefender

Objective

Understand which Windows data sources answer the core SOC questions: what ran, who ran it, what created it, what it connected to, what it changed and whether authentication succeeded.

Telemetry configuration

  • Enabled successful and failed logon auditing.
  • Enabled process creation auditing and command-line capture.
  • Enabled the PowerShell Operational channel and Script Block Logging.
  • Installed Sysmon with a focused configuration for process, network and file visibility.
  • Reviewed Microsoft Defender detection and remediation events.

Configuration was validated by deliberately generating benign test activity and finding the resulting events by timestamp, process and user.

Process reconstruction

A known Notepad launch was used to practise reading process lineage. The event showed the executable path, full command line, user, integrity level and PowerShell parent.

ParentImage: C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe Image: C:\Windows\System32\notepad.exe CommandLine: notepad.exe C:\SOC-Lab\incident.txt User: DESKTOP\analyst Integrity: High

PID versus Process GUID

A PID identifies a currently running process but can be reused after termination. Sysmon's ProcessGuid uniquely identifies that process instance and supports reliable correlation between process, network and file events.

Triage questions

  1. Is the executable path expected for this image?
  2. Is the parent-child relationship normal for the application?
  3. Does the command line match the user's task?
  4. Did the process create files, persistence or outbound connections?
  5. What integrity level and account context did it use?
  6. Are there Defender, authentication or PowerShell events nearby?

Result

8high-value event types reviewed
4Windows log channels correlated
1repeatable triage checklist created

The lab established a practical baseline for endpoint investigations and created the telemetry foundation required before writing higher-level SIEM detections.
