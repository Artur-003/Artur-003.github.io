Network Foundations

A set of Cisco Packet Tracer and host-level exercises connecting Ethernet, IP routing and core application services to the evidence a SOC analyst sees.

Packet TracerTCP/IPARPVLANACLDNSHTTP/S

Objective

Move beyond memorising protocols and understand how normal traffic is generated, forwarded and represented in endpoint, firewall and packet-capture evidence.

Ethernet LAN exercise

Built a two-host switched LAN, assigned IPv4 addresses, verified connectivity and examined the endpoint ARP cache and switch MAC address table.

PC1 ── Fa0/1 [ Switch ] Fa0/2 ── PC2 ping 192.168.1.20 arp -a show mac address-table dynamic

Observed sequence

  1. The sender determines that the destination is in the local subnet.
  2. An ARP request is broadcast because the destination MAC address is unknown.
  3. The target returns a unicast ARP reply.
  4. The ICMP echo request is sent in an Ethernet frame addressed to the learned MAC.
  5. The switch learns source MAC addresses on ingress ports and forwards known unicast traffic to the correct port.

Segmentation and access control

  • Calculated network, broadcast and usable host ranges for common prefixes.
  • Used VLANs to understand broadcast-domain separation and trunk links.
  • Compared standard ACLs, which inspect source IP, with extended ACLs that also inspect destination, protocol and port.
  • Reviewed NAT/PAT, default gateways and the TTL change across routed hops.
  • Connected VPN and firewall concepts to remote-access and site-to-site security.

An ACL is stateless rule matching. A stateful firewall also tracks connection state and can apply richer inspection and logging.
