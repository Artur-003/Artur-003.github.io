Home SOC Laboratory

An isolated virtual environment for generating security telemetry, testing detections and conducting repeatable incident investigations.

VirtualBoxWindows 10Kali LinuxWazuhOPNsenseZeekSuricata

Design goal

Create a safe and observable environment where test activity has a known start time and expected outcome. The lab separates simulation, monitored endpoints, central analysis and network sensing so that one event can be viewed from multiple perspectives.

The environment is isolated and used only for authorised training. No testing targets systems outside the laboratory.

Evidence flow

  1. Generate a controlled action from an identified system.
  2. Record the exact timestamp and expected artefacts.
  3. Collect endpoint events through the Wazuh agent.
  4. Review firewall, Zeek or Suricata data for independent network context.
  5. Correlate host and network evidence into one timeline.
  6. Document the verdict and convert the useful observation into detection logic.

Result

The lab provides the foundation for portfolio cases without overstating production experience: every claim can be tied to a controlled action, an event record and an analyst conclusion.

Planned improvements

  • Add a small Active Directory environment for Kerberos, LDAP and domain telemetry.
  • Version detection rules and test data alongside the reports.
  • Standardise screenshots and evidence redaction before publication.
  • Measure rule quality using expected true-positive and benign control events.
