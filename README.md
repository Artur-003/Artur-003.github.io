# Artur Ivanov — SOC / DFIR Portfolio

Source code for my practical cybersecurity portfolio: hands-on SOC labs, detections, Windows and network telemetry, and incident investigations.

## Live site

`https://artur-003.github.io`

## Portfolio principles

- Every claim is supported by a controlled lab or written investigation.
- Reports separate observed facts from analyst inference.
- Sensitive values, credentials and unnecessary personal data are removed before publication.
- Activity is performed only in authorised training environments.
- Projects are written as: objective → environment → actions → evidence → analysis → result.

## Adding a new project

1. Copy `PROJECT_TEMPLATE.md` and complete the evidence review.
2. Create a project page inside `projects/` using the existing case studies as a layout reference.
3. Add a project card to `index.html`.
4. Verify that no credentials, private addresses tied to real infrastructure, tokens or personal data are exposed.
5. Test every link and view the page on desktop and mobile before publishing.

## Technology

Plain HTML, CSS and JavaScript. No framework, external tracking or third-party runtime dependency.

## Ethics

All security testing described in this portfolio was performed in isolated systems owned and controlled by me or on authorised training platforms.
